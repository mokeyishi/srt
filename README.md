## Grab4K 115 一键转存助手（增强版）

仓库内用户脚本：`grab4k-115-helper.user.js`，用于在 Grab4K 页面执行 115 转存。

### 已支持能力

- 修复“复制成功但提示未获取到115链接”问题：严格走“点击复制按钮→读取剪贴板”流程，不再依赖按钮/DOM中的静态链接。
- 内容页（`/down/`）资源行按钮：`一键转存`。
- 内容页仅 1 个资源时自动点击“一键转存”；多个资源时保持手动点击。
- 内容页多资源可“选择后批量转存”。
- 影片标题提取优先当前资源行，避免总是取首页标题。
- 支持异步加载场景（MutationObserver）。

### 新增：筛选页批量转存流程

- 在筛选页右下角新增“筛选页批量转存”面板。
- 开启“一键转存模式”后：
  - 点击筛选页任意影片卡片，会新开内容页并带批量参数。
  - 如果内容页只有 1 个资源：自动转存，成功后自动关闭该页。
  - 如果内容页有多个资源：手动点击某个“ 一键转存 ”按钮，成功后自动关闭该页。
- 增加“转存日志”：成功/跳过/失败都会记录为“状态 + 影片名 + 时间 + 信息”，支持清空。
